This capability functions exclusively as a static analysis and code review tool. Its primary objective is to scan the provided code to identify flaws, incorrect paths, or incompatibilities regarding the import of libraries, plugins, and frameworks. It operates in a strictly read-only mode, limiting itself to diagnosing and reporting issues without modifying the original files.
